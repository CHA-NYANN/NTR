# Perbaikan panel referensi dan pilihan tindakan

Pemilik meminta panel dialog bergeser ke kiri agar seimbang dengan HP di kanan, teks berjarak dari tepi bawah, lubang kertas tetap bulat dan jumlahnya mengikuti tinggi panel. Desain Figma yang sudah disetujui tetap menjadi sumber gambar. Pilihan tindakan pada GUI custom memakai ilustrasi yang menjadi tombolnya sendiri.

## Panel referensi

- `game/zz_kk_gui.rpy`, menu utama, peta utama, kontrol dialog, HP serta SVG/PNG referensi asli tidak diubah.
- `game/zzz_kk_secondary.rpy` mengukur hasil layout teks dengan font Ren'Py sebenarnya. Tinggi panel dipilih berdasarkan baris yang terukur, termasuk ruang untuk penanda lanjut. Tidak lagi memakai perkiraan jumlah karakter.
- `tools/build_dialogue_variants.py` menurunkan varian dari kelompok SVG referensi. Tepi bawah berpindah; badge, pita, lipatan, indikator dan lingkaran tidak dipipihkan. Jarak lubang tetap, jumlah lubang berubah. Kemiringan sisi System mengikuti tepi aslinya.
- Panel biasa berada di x=80, lebar 1596 pada kanvas 1920×1080. Tepi kanan panel berjarak 82 dari area tombol HP yang tetap di x=1758. Teks memiliki ruang bawah 78 piksel di luar area bacanya; ornamen berada di ruang tersebut.
- System memakai badge dan gradien asli, teks tebal yang dapat diedit pada skrip, tanpa menambahkan judul `SISTEM NTR` di atas teks. Nama karakter tetap berada pada history. Panel tidak memakai Frame yang mendistorsi bentuk aslinya.
- `tools/build_choice_variants.py` menambah tinggi pilihan dialog panjang tanpa memipihkan perforasi. Pilihan jawaban percakapan tetap berupa kertas sesuai referensi.
- Untuk paragraf di luar tinggi maksimum layar, area baca dapat digulir. Naskah tidak dipotong atau ditulis ulang.

## Tindakan bergambar

- Pemilihan tangan memakai dua PNG transparan di atas latar hampir hitam. Seluruh siluet tangan menjadi imagebutton dengan `focus_mask True`; area transparan tidak memilih rute. Tangan pria mengembalikan `yutaka`, tangan wanita `chiasa` seperti sebelumnya. Ada animasi muncul, hover dan transisi pilihan.
- Empat tindakan pembuka Yutaka dan Chiasa memakai dompet/ponsel, cermin/sketsa, telepon, pintu/tangga atau kursi sesuai isi pilihan. Action Return A/B/C/D tetap sama. Caption asli tersedia saat hover/fokus serta melalui teks aksesibilitas.
- Aktivitas lokasi pada GUI custom memakai ilustrasi makan, kerja, buku, kursi, kereta, catur dan tempat tidur. Ilustrasi adalah tombolnya; nama, biaya dan efek lama tersedia pada hover/fokus. Aktivitas tidak tersedia tetap nonaktif. Operasi perjalanan, aktivitas, percakapan dan istirahat tidak diubah.
- Caption tetap berasal dari data/naskah lama. Tidak ada pemetaan atau penambahan canon karakter. Gambar tangan merupakan ilustrasi anonim untuk adegan pemilihan tubuh.
- `tools/action_art_manifest.json` menyimpan prompt final dan alat untuk tujuh PNG yang dibuat dengan image_gen bawaan. File proyek berada di `game/gui/kouseikan/actions/`. Objek aktivitas tambahan memakai SVG native melalui `tools/build_action_objects.py`.

## Pemeriksaan

`tools/run_dialogue_action_qa.py <renpy-sdk> [folder-hasil]` menyalin game tanpa save/cache pemain lalu menguji layout dialog netral, Yutaka, Chiasa, dark dan System; kedua Return tangan dan mask alpha; delapan tindakan pembuka; aktivitas lokasi; serta C02 panjang cabang A/B/C. Capture berada pada folder hasil, tidak masuk game rilis.

`tools/check_secondary_scope.py --portable` tetap mengunci file/aset referensi, menu utama, peta utama, kontrol dialog dan tampilan awal HP. Pengecualian baru hanya screen pemilihan tangan custom yang secara eksplisit diminta pemilik pada 19 November 2026. Urutan Return pada aktivitas lokasi juga diperiksa.

Perbaikan ini tidak mengubah cerita, jadwal, harga, efek, katalog autogenerated atau save pemain. Validasi desktop dicatat pada PR; Android/touchscreen dan playthrough penuh belum dicakup.
