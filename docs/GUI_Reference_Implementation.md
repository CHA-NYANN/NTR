# GUI Kouseikan — implementasi referensi

Permintaan pemilik proyek: menerapkan GUI referensi langsung ke proyek Ren'Py. Keputusan terbaru: pin keberadaan NPC ditampilkan menggunakan **inisial sampai potret final tersedia**.

## Sistem dan file

- `game/zz_kk_gui.rpy`: lapisan tampilan tambahan; mengganti screen dengan nama/API yang sama tanpa mengedit alur cerita.
- `game/gui/kouseikan/`: dekorasi terpisah, ilustrasi, ikon, font dan lisensinya. Teks dan area tombol tidak dibakar ke gambar.
- `tools/figma-art/` dan `tools/icons.json`: sumber ekspor dekorasi Figma tanpa teks.
- `tools/build_gui_assets.py`: merender dekorasi SVG menjadi PNG. Dependensi pengembangan di `tools/requirements-gui.txt`; game tidak memerlukan dependensi Python tambahan.
- `tools/run_gui_qa.py`: uji layar, simpan/muat sungguhan dan replay dengan save terpisah.
- `tools/run_gui_integration.py`: menjalankan suite `tests/run_living.py` yang sudah ada terhadap screen tambahan. Penggerak pengujian hanya disisipkan ke salinan sementara.

Figma sumber: https://www.figma.com/design/lYsY4q9tqchOPJv0JCjexD

## Tampilan dan tindakan

- Main menu: New Game, Continue, Settings, Gallery, Load Slots, System dan Exit memakai tindakan Ren'Py.
- Dialog: varian Yutaka, Chiasa, gelap dan System neon. Nama, isi dialog dan pilihan adalah teks Ren'Py, dapat diedit dalam naskah `.rpy` yang bersangkutan.
- Bilah dialog: skip, baca otomatis, sembunyikan GUI, riwayat, simpan, muat dan HP.
- Album save/load: enam slot per halaman, thumbnail save aktual, waktu, halaman manual/otomatis/cepat dan tombol hapus standar pada slot yang terfokus.
- Settings: kecepatan teks, jeda otomatis, musik, efek suara, mode layar dan varian dialog gelap.
- Gallery: hanya adegan yang sudah dilihat dan mempunyai label implementasi. Replay berjalan di konteks Ren'Py terpisah; pilihan replay tidak mengganti progres aktif.
- Peta: tujuh distrik dan 37 lokasi dari registry game. Pemilihan distrik/lokasi mengembalikan nilai yang sama ke alur perjalanan yang sudah ada. Konfirmasi lokasi dapat dibatalkan. Biaya waktu tetap dihitung oleh alur lama.
- Inisial pin berasal dari nama NPC dan lokasi `kk_daily_place`. Tidak ada potret sementara yang dipasangkan secara sembarang. HP menampilkan lokasi yang sama dan peta tinjau tanpa teleportasi.
- Pesan HP membaca antrean pesan yang sudah tersedia. Penyampaian adegan pesan tetap menggunakan alur aktivitas game.
- Tombol Home di HP membuka menu game: lanjut bermain, simpan, muat, pengaturan, galeri, System, menu utama dan keluar. HP ditutup saat menu dibuka sehingga tidak menghalangi input; lanjut bermain kembali ke keadaan permainan yang sama.
- Status, transaksi, alat uji, aktivitas lokasi dan screen pendukung lama dipertahankan; warna, font dan tombol dasarnya mengikuti tema baru.

Referensi peta 4:3 disesuaikan ke kanvas game **1920×1080**. Resolusi dasar proyek tidak diubah. Ilustrasi kota adalah aset raster tersendiri; label, inisial, waktu, daftar lokasi dan seluruh interaksi tetap terpisah.

## Mengedit dan menonaktifkan

Ubah teks cerita dalam file cerita aslinya; ubah label GUI dalam `zz_kk_gui.rpy`. Ganti aset di folder `gui/kouseikan` dengan nama yang sama untuk reskin. Tidak perlu mengedit gambar untuk mengganti teks.

Lapisan ini tidak memigrasikan atau menghapus save, tidak mengubah event autogenerated, dan tidak mengganti keputusan canon. Untuk kembali ke GUI lama, nonaktifkan lapisan `zz_kk_gui.rpy` beserta hasil kompilasinya melalui perubahan terpisah yang ditinjau; jangan menghapus save.

## Verifikasi

Pengujian menggunakan Ren'Py 8.3.2, proyek salinan dan direktori save terpisah. Lint bersih; audit katalog: event utama 182/190, event dinamis 128/128, ending 220/220 (cakupan yang sudah ada, bukan klaim semua konten baru selesai).

Uji GUI memeriksa 37 lokasi, kecocokan jadwal pin, pilihan distrik/lokasi, batal/konfirmasi, tab HP, peta tinjau, varian dialog, pilihan, Settings, save/load sungguhan, History, System dan replay galeri. Pemulihan nilai game setelah load dan pemisahan progres replay diuji.

Keterbatasan: belum diuji pada Android/touchscreen atau semua ukuran jendela; potret final belum tersedia; pengujian ini bukan playthrough seluruh cerita. Sumber ilustrasi dan dekorasi mengikuti file desain yang diberikan/disetujui pemilik proyek.

Lisensi font: Kalam dan Nunito dari google/fonts; Tinos dari googlefonts/tinos. Teks lisensi lengkap disertakan di folder `fonts/`.
