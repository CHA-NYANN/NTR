# Urutan ID penulisan Kouseikan untuk Antigravity

Urutan berikut mengikuti bulan/subfase pada katalog utama. Ini urutan kerja penulisan, bukan perintah membuat semua event wajib dimainkan atau menjadwalkan node penutup. Dalam bulan yang sama, posisi antar-event dapat disesuaikan dengan prasyarat kode dan alur yang disetujui; tabel tidak menetapkan bahwa satu pilihan tertentu sudah diambil.

Rangkaian tersebut sudah berurutan, tetapi bukan seluruh cerita dari hari ke hari. C02 berada di M01a, sedangkan C03 baru M04. Gunakan tabel bulanan jika ingin menyusun cerita lintas tokoh secara kronologis.

## Instruksi siap kirim ke Antigravity

> Gunakan docs/Gemini_Urutan_Penulisan.md. Mulai dari host Chiasa, kolom Chiasa, dari atas ke bawah. Kerjakan satu event sesuai urutan bulan, dan pecah event panjang menjadi bagian-bagian. Periksa prasyarat kode sebelum menetapkan hubungan atau pengetahuan tokoh. Sisipkan event dinamis yang relevan sesuai pemicunya, bukan otomatis menurut nomor -D. Setiap bagian harus melanjutkan keadaan terakhir yang sudah disetujui. Tulis panjang dan rinci, kemudian berhenti menunggu ACC. Jangan melompati event yang belum disetujui atau berpindah host.

## Catatan penting

- C01 dan Y01 memakai label prolog bersama: saat menulis salah satunya, pertahankan cabang host lainnya.
- M01a/M01b, M05a/M05b, dan M29a/M29b adalah urutan subfase katalog.
- Event dalam satu bulan tetap memiliki pemicu dan bisa opsional. Jangan mengarang urutan pasti jika kode tidak menetapkannya.
- C18, Y19, K26, K27, Mi27, N24, H24, S25 adalah node penutup yang sudah disediakan; jangan menambahkan pemanggilan scheduler.
- Ending ditulis setelah alur dan syarat hasil terkait jelas; bukan semuanya dijadikan kejadian dalam satu jalur.
