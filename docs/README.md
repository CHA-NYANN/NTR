## Catatan konsistensi — perlu keputusan pemilik proyek

Catatan berikut **hanya menunjukkan perbedaan file yang ditemukan**, bukan koreksi canon:

- **Nama versi Master Canon:** pada bagian awal [GDD v1.29](../GDD/GDD_Kouseikan_v1.29.md) tertulis referensi `Master_Canon_Visual_Novel_Kouseikan_v11.1.md`, sedangkan file dalam repository saat pemeriksaan adalah `Master_Canon_Visual_Novel_Kouseikan_v11.md`. Jangan mengganti rujukan atau menaikkan versi secara otomatis sebelum sumber yang dimaksud dipastikan.
- **[story_bible.md](story_bible.md):** dokumen ini memuat premis dan tokoh Arga, Nadia, serta Bima, berbeda dari latar Kouseikan pada Master Canon/GDD. Statusnya (alternatif, eksplorasi, atau arsip) **belum dikonfirmasi**. Dokumen asli tetap dipertahankan dan tidak boleh dipakai untuk menimpa canon Kouseikan tanpa keputusan eksplisit.
- **Generator data:** [PROTOTIPE_RENPY.md](../PROTOTIPE_RENPY.md) menjelaskan bahwa data `game/kk_data_kk_*.rpy` dihasilkan dari dokumen melalui `gen_rpy.mjs` di scratchpad. Skrip generator tersebut tidak ditemukan dalam tree Git yang diperiksa. Pertahankan source data dan jangan regenerasi manual tanpa alurnya.
- **Log pengujian:** `errors.txt` dan `traceback.txt` di root mencatat error dari sesi sebelumnya; ini bukan bukti definitif bahwa kode sekarang masih error. Verifikasi dengan lint dan menjalankan prototipe.
- **File hasil berjalan:** repository sudah melacak sejumlah cache Ren'Py, `.rpyc`, save, dan log. `.gitignore` yang baru hanya mencegah penambahan file tak terlacak; file lama tetap utuh dan terlacak sampai ada keputusan pembersihan terpisah.

## Aturan aman saat menyunting dokumen

1. **Pertahankan dokumen asli dan jejak versi.** Perubahan canon harus melalui keputusan eksplisit pemilik proyek, sesuai aturan Master Canon.
2. Pisahkan **canon**, **usulan**, **implementasi prototipe**, dan **catatan historis**. Jangan menaikkan status usulan menjadi canon dengan menyunting indeks.
3. Gunakan *branch* dan *pull request* untuk perubahan berikutnya agar perbandingan file mudah ditinjau.
4. Jangan mengedit massal file event/ending autogenerated atau membuang save, log, dan aset tanpa persetujuan eksplisit.
