# Karakter Kouseikan — Indeks

Draft pertama. Sumber canon: `GDD/GDD_Kouseikan_v1.29.md` dan `GDD/Master_Canon_Visual_Novel_Kouseikan_v11.md`.

## Legenda (berlaku di semua file)
- ✅ **CANON** — sudah ada di GDD / Master Canon (sudah kamu putuskan).
- 🟡 **USULAN** — isian dariku untuk hal yang belum diputuskan. **Bukan canon** sampai kamu ACC. Edit/hapus bebas.
- ❓ **KEPUTUSAN** — pertanyaan yang butuh jawabanmu.

Aturan (keputusanmu): game **18+**, semua tokoh dewasa. Konten dewasa boleh di teks, **tanpa ilustrasi seksual eksplisit**. Kematian, bunuh diri, dan tragedi boleh tampil penuh. Satu batas dariku: tidak menulis metode bunuh diri.
